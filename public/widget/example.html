속성 설명

data-codipop-key발급받은 공개 키. 페이지에 노출되어도 되는 값이며, 허용 도메인에서만 동작합니다.
data-codipop-product상품 코드. 리포트에서 상품을 구분하는 기준이 됩니다.
data-codipop-name상품명. 넣으면 리포트에 코드 대신 이름으로 표시됩니다.
data-codipop-price가격(숫자). 피팅 후 구매 클릭의 추정 매출을 계산합니다.
data-codipop-image상품 이미지 주소. 누끼 이미지를 따로 만들 필요 없이 지금 쓰는 상품 사진 그대로 넣으면 됩니다.
data-codipop-buy구매 또는 장바구니 주소. 생략하면 현재 페이지로 돌아옵니다.
data-codipop-categoryTOP / BOTTOM / OUTER / DRESS. 사이즈 추천 정확도가 올라갑니다. (선택)
data-codipop-sizes상품 표기 사이즈(예: M). 넣으면 "이 상품은 한 치수 크게" 같은 안내가 가능합니다. (선택)

생략하면 어떻게 되나요

이미지·상품명을 적지 않으면 위젯이 페이지에서 스스로 찾습니다 (OG 태그 → 페이지에서 가장 큰 이미지 순). 다만 리포트의 정확도가 떨어지므로 상품 코드와 이름은 넣는 것을 권장합니다.
