이 페이지는 쇼핑몰 상품 상세를 흉내 낸 예시입니다

아래 '착용해 보기' 버튼은 코디팝이 넣은 것이 아니라, 스크립트 한 줄이 스스로 만든 것입니다.

오버핏 코튼 셔츠

39,000원

어깨선을 내린 오버핏 실루엣. 사계절 입기 좋은 두께감입니다.

상품이 1,000개여도 작업은 한 번입니다

쇼핑몰의 상품 상세는 템플릿 1개입니다. 상품마다 페이지가 따로 있는 게 아니라, 같은 템플릿에 상품 데이터만 갈아끼워 보여줍니다. 그래서 템플릿 한 번만 수정하면 전 상품에 적용됩니다.

방법 ①: HTML을 한 줄도 안 만지는 방법 (권장)

구매 버튼의 CSS 선택자만 알려주시면, 저희가 그 옆에 버튼을 만듭니다.

<script src="https://codipop-backend.onrender.com/widget.js"
        data-codipop-key="pk_demo_mall"
        data-codipop-after=".btn-buy"
        data-codipop-product-param="branduid"
        data-codipop-name-selector=".prd-name"
        data-codipop-price-selector=".prd-price"></script>
data-codipop-after이 요소 뒤에 버튼을 넣습니다. before(앞) / into(안쪽)도 됩니다. 같은 선택자가 여러 개면 첫 번째에만 붙습니다.
data-codipop-product-param상품 코드를 주소에서 읽습니다. 예: ?branduid=1170620 → branduid. 리포트가 상품별로 정확해집니다.
data-codipop-name-selector상품명이 들어 있는 요소. (선택)
data-codipop-price-selector가격이 들어 있는 요소. 숫자만 뽑아 씁니다. (선택)
data-codipop-image-selector상품 이미지 요소. 생략하면 페이지에서 가장 큰 이미지를 씁니다. (선택)

구매 버튼이 나중에 그려지는 페이지도 괜찮습니다. 버튼이 나타날 때까지 잠시 기다렸다가 붙입니다.

방법 ②: 상품 정보를 직접 넣는 방법

템플릿 변수를 쓸 수 있으면 이쪽이 가장 정확합니다.

<!-- ① 페이지 어딘가에 한 번 -->
<script src="https://codipop-backend.onrender.com/widget.js"
        data-codipop-key="pk_demo_mall" defer></script>

<!-- ② 버튼을 넣고 싶은 자리에 -->
<div data-codipop-button
     data-codipop-product="상품코드"
     data-codipop-name="상품명"
     data-codipop-price="39000"
     data-codipop-image="상품 이미지 주소"
     data-codipop-buy="구매/장바구니 주소"></div>

"상품코드" 자리에는 고정값이 아니라 쇼핑몰 템플릿 변수를 넣습니다. 변수 이름은 플랫폼마다 다르므로(카페24·메이크샵·고도몰이 각각 다릅니다), 이미 그 템플릿에서 상품명·가격을 출력하고 있는 변수를 그대로 복사하시면 됩니다. 연동 때 저희가 함께 확인해 드립니다.

속성 설명

data-codipop-key발급받은 공개 키. 페이지에 노출되어도 되는 값이며, 허용 도메인에서만 동작합니다.
data-codipop-product상품 코드. 리포트에서 상품을 구분하는 기준이 됩니다.
data-codipop-name상품명. 넣으면 리포트에 코드 대신 이름으로 표시됩니다.
data-codipop-price가격(숫자). 피팅 후 구매 클릭의 추정 매출을 계산합니다.
data-codipop-image상품 이미지 주소. 누끼 이미지를 따로 만들 필요 없이 지금 쓰는 상품 사진 그대로 넣으면 됩니다.
data-codipop-buy구매 또는 장바구니 주소. 생략하면 현재 페이지로 돌아옵니다.
data-codipop-categoryTOP / BOTTOM / OUTER / DRESS. 사이즈 추천 정확도가 올라갑니다. (선택)
data-codipop-sizes 판매 사이즈. 쇼핑몰에 적어두신 표기를 그대로 넣으시면 됩니다 — F(55~66), FREE, S,M,L, 55,66 모두 인식합니다.
넣으시면 그 상품에 없는 사이즈를 추천하지 않습니다. 프리 사이즈 상품이면 "이 고객님께는 타이트할 수 있습니다"처럼 안내합니다. (선택)

생략하면 어떻게 되나요

이미지·상품명을 적지 않으면 위젯이 페이지에서 스스로 찾습니다 (OG 태그 → 페이지에서 가장 큰 이미지 순). 다만 리포트의 정확도가 떨어지므로 상품 코드와 이름은 넣는 것을 권장합니다.
